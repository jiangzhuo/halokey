# halokey 设置界面重做 · 设计文档

> 2026-10-17 · 已与 jiangzhuo 逐节确认（线框见 `.superpowers/brainstorm/31689-1792191710/content/`）。
> 本文是实施计划的依据；内部工作文档，只有中文版。

## 1. 目标与范围

**目标**：把现在的调试面板换成一个与 olanzi（macOS 原生应用）同等完成度、VIA 式操作习惯的桌面设置界面，并补上 halokey 独有的三样东西：每层背光、光环菜单、指针移动。

**成功标准**

- 用户不看 JSON 也能完成全部配置：键位（四层 × 三手势）、组合键录制、APP、宏、光环、指针移动、每层背光、设备设置。
- 视觉与信息架构对得上 olanzi 的截图（深色、设备居中、手势卡片、分类键码面板、底部撤销 / 保存）。
- 光环转盘是 Surface Dial 式扇形环，出现在鼠标指针周围。
- 全部在这台 Linux（GNOME / X11）机器上真机验证。

**非目标（本期不做）**

- 多套预设与按应用自动切换（已决定：单套配置）。
- 固件 OTA（需要复刻 Studio 的升级协议）。
- Wayland、macOS、Windows 的真机验证。
- 插件市场、云服务。

## 2. 技术栈

- 前端：**Svelte 5 + Vite + TypeScript**，无 UI 框架依赖；样式用 CSS 变量，深色默认，浅色主题为变量替换。
- 两个入口页：`index.html`（主窗口）、`halo.html`（转盘悬浮窗），Vite 多页构建到 `ui/dist`。
- Tauri 2 配置：`build.beforeBuildCommand = "npm run build"`、`beforeDevCommand = "npm run dev"`、`devUrl = http://localhost:5173`、`frontendDist = ../../ui/dist`。CI 在 cargo 之前 `npm ci && npm run build`。
- 类型：`ui/src/model/keymap.ts` 手写 `HostKeymap` 等类型，与 Rust 的 JSON 形状一一对应；用 vitest 对示例 JSON 做往返测试。
- 后端不换：`crates/runtime` 的命令 / 快照 / 事件接口在此基础上扩展（见 §8）。

## 4. 键位页

### 4.1 Layer 条

- 四个层按钮，等宽等高，当前层高亮；非基础层的手势若为透明继承，卡片显示 ▽。
- **本层背光条**（新）：四盏灯各一个状态圆点（关 = 灰、常亮 = 暖色、呼吸 = 闪烁动画）+ 名称 + 模式文字，右侧"亮度 N"和"编辑…"。
  - 点"编辑…"在条下方展开：每盏灯一行 [关][常亮][呼吸] 分段按钮 + 亮度滑块 0–20；最右一个"跟随 Layer 0"开关（Layer 0 本身没有这个开关）。
  - 关闭"跟随 Layer 0"即为本层创建背光记录；打开即删除记录。
- 设备渲染图上的灯圈实时反映当前编辑层的背光（呼吸用 CSS 动画）。

### 4.2 设备渲染图

- 自绘 SVG（不用任何第三方素材）：浅色机身、顶部麦克风格栅、大旋钮、三个圆形按键，按键周围一圈可着色的灯环。
- 旋钮两侧挂"左旋 / 右旋"标签，显示当前动作，点击即选中该手势。
- 点设备上的键 / 旋钮 = 选中该控件的单击手势（与点卡片等价）。

### 4.3 手势卡片

- 键 1 / 2 / 3 / 旋钮按下各一张，三列：单击 · 双击 · 长按；每列显示动作简名（`Fn`、`切换到 Chrome`、`光环「主菜单」`、`指针 ↓40`），关闭显示 ⊠，透明继承显示 ▽。
- 选中列高亮；键码面板面包屑随之变为「控件 › 手势」。
- 旋转手势只有单击，卡片只有一列。

### 4.4 键码面板

分类（左栏，顺序固定）：常用 · 字母 · 功能键 · 数字键盘 · 鼠标 ｜ 组合键 · Layer · APP · 宏 · 光环 · 指针。

- 键帽分类（常用 / 字母 / 功能键 / 数字键盘 / 鼠标）：网格键帽，点击即分配；首格固定两个特殊键帽：▽ 透明继承（非基础层）、⊠ 不执行 / 关闭手势。鼠标分类含左 / 右 / 中 / 键 4 / 键 5 / 滚轮↑ / 滚轮↓。
- 组合键：录制框（抓真实键盘按键，最多 4 个修饰键 + 1 个主键）+ "分配组合键"；也可手动勾修饰键 + 选主键。
- Layer：▽、⊠、MO(1)、MO(2)、MO(3)；仅按键与旋钮按下的单击 / 长按可用。
- APP：卡片 A0 A1 A2…（名称 + WM_CLASS），"添加 APP"打开 APP 编辑器（名称、WM_CLASS、可执行文件路径、从当前打开的窗口列表里挑）。
- 宏：卡片 M0 M1…，"新建宏"打开宏编辑器（与 olanzi 相同：APP / 等待 / 组合键三种步骤，上下移、删除，录制模式）。
- 光环：卡片 H0 H1…，"新建光环"打开光环编辑器（§5）。
- 指针：方向 ↑↓←→ 四个键帽 + 步长输入（像素，默认 20），组合成 `pointerMove`。
- 输出方式分段按钮：保持按住 / 短按一次 / 连按（带 − N + 步进器，2–20）；规则与 olanzi 相同（旋转和双击不能保持按住）。

### 4.5 保存与撤销

- 所有改动先进内存草稿；底栏"保存到本机"校验（调用 Rust 的 `validate`）后写文件并下发 `SetKeymap`；"撤销更改"回到上次保存。
- 有未保存改动时顶栏页签旁显示一个小圆点；关闭窗口不丢草稿（窗口只是隐藏）。

## 5. 光环菜单

### 5.1 编辑器

整页打开（返回箭头 + 标题 + 名称输入框）。

- 左：环形预览，8 个扇形槽位（SVG），有动作的槽位显示名称 + 动作简名，空槽显示 ＋；点扇形选中槽位。
- 右：槽位列表 1–8：名称输入、动作简名、上移 / 下移 / 删除。
- 下：复用键码面板（去掉 Layer 分类），给选中槽位选动作；动作可以是另一个光环。
- 底栏：取消 · 保存光环。空槽位不写进配置（配置里 options 只含有效项，顺序即槽位顺序）。

### 5.2 转盘悬浮窗

- 扇形环：外径按"大小"设置（小 / 中 / 大 = 280 / 360 / 440 px），内径约 60%，N 个等分扇形从 12 点钟方向顺时针排；高亮扇形用强调色填充，其余半透明深色；中心圆显示高亮项名称；底部一行提示"拧旋钮选择 · 按下确认 · 按任意键取消"。
- 出现位置：鼠标指针周围（默认）或屏幕中央；超时 4 秒（可设）。
- 行为不变：转动选择、按下确认、任意键取消、超时关闭；事件由 runtime 推送。
- 窗口：透明、无边框、置顶、不进任务栏、不可聚焦；Wayland 下退化为普通置顶失败时仍可见（记录为已知限制）。

## 6. 设置页

七张卡，每项改动立即写入设备并读回核对，失败在该行右侧红字提示；没有保存按钮。

| 卡 | 内容 |
|---|---|
| Vibe Key | 状态行（连接 · 本体在线 · 电量 · 电压 · 心跳 / 回显计数）；固件（本体 / 接收器）；空闲后交还控制（永不 / 1 / 5 / 10 / 15 / 30 / 60 分钟）；设备自身键位（写入设备、从设备读取）；连接帮助（折叠：udev 规则、插拔、待机唤醒）；按钮：刷新状态、断开连接 |
| 灯光 | 灯光模式 [全灭][全亮][工作]；全亮亮度滑块 0–20；提示"各灯效果在键位页按 Layer 设置" |

## 7. 数据模型变更（配置版本 6）

```jsonc
// keymap.json
{
  "version": 6,
  "lighting": { "lights": [ { "mode": "breathe", "brightness": 14 }, … ×4 ] },   // Layer 0 背光（可缺省 = 不管灯）
  "layers": [ { "id": 1, "controls": [ … ], "lighting": { "lights": [ … ] } } ],   // 可缺省 = 跟随 Layer 0
  "halos": [ … ]   // 不变
}
// settings.json（应用偏好，不进键位文件）
{ "idleMinutes": 5, "language": "zh", "theme": "system", "closeToTray": true,
  "halo": { "position": "pointer", "timeoutSeconds": 4, "size": "medium" } }
```

- `LightEffect { mode: off|solid|breathe, brightness: 0–20 }` 映射到设备记录：`kind` = 0/1/2，`brightness` 同时写入 `always_on_brightness` 与 `breathe_brightness`；`work_time`、`breathe_level` 保持设备现值。
- Rust 侧：`HostKeymap.lighting: Option<LayerLighting>`、`HostLayer.lighting: Option<LayerLighting>`，参与 `required_version`（存在即 6）。
- 运行时：活动层集合变化时，取编号最高且带背光的活动层，否则 Layer 0；与上次写入的有效背光比较，不同才写设备；写入经 100 ms 防抖，走现有 `set_lighting` 的最小差异序列。所有层都没有背光时不碰灯。
- 灯光模式 / 全亮亮度不在键位文件里，由设置页直接写设备。

## 8. 前后端接口

Tauri 命令（在现有基础上增删）：

| 命令 | 说明 |
|---|---|
| `snapshot` | 增加 `paused / standby / link / activeLayers / effectiveLighting` |
| `get_keymap` / `save_keymap` | 不变；`save_keymap` 先校验再写文件再下发 |
| `validate_keymap(json)` | 新增：只校验不保存，供前端实时显示错误 |
| `read_device_keys` / `write_device_keys` | 不变 |
| `device_info` / `power_info` / `set_lighting_mode(mode, brightness)` / `set_sleep_delay` / `set_standby_delay` / `set_mic_enabled` / `set_noise_reduction` | 灯光拆成全局（模式 + 亮度）一条；四灯由运行时按层写 |
| `get_settings` / `set_settings(partial)` | 取代 `get_autostart / set_autostart / set_idle_minutes`，一次写 `settings.json` 并即时生效 |
| `list_windows` | 新增：返回当前 X11 顶层窗口的 WM_CLASS 与标题，供 APP 编辑器挑选 |
| `set_default_audio_input` | 新增：Linux 用 `pactl set-default-source` |
| `open_log_dir` / `import_keymap(path)` / `export_keymap(path)` | 新增；文件对话框用 `tauri-plugin-dialog` |

事件 `halokey`（不变 + 新增）：`connected / disconnected / key / battery / error / paused / resumed / haloShow / haloSelect / haloHide / layers { active: [1] }`。

## 9. 错误处理

- 设备写入失败：行内红字 + 事件日志；不弹窗。
- 保存校验失败：底栏红字显示 Rust 返回的中文错误，并高亮出错的卡片 / 槽位（错误里带 `index` / `halo` 字段）。
- 接收器断开：顶栏状态变灰，键位页可继续编辑，设备写入类按钮禁用。
- 转盘窗口创建失败（Wayland 等）：光环动作退化为"仅日志"，设置页显示一次性提示。
